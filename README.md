# 🛒 বাজার দর (BazarDor)

প্রয়োজনীয় পণ্যের দৈনিক বাজার দর এক নজরে দেখার ওয়েবসাইট। কোন পণ্যের দাম বাড়ছে বা কমছে, ক্যাটাগরি অনুযায়ী পণ্য, আর বিভিন্ন বাজারের দামের তুলনা — সবকিছু বাংলায়, মোবাইল থেকে ডেস্কটপ পর্যন্ত রেসপন্সিভ ডিজাইনে।

- **GitHub Repository:** _(রিপো লিংক এখানে বসান)_

## ✨ Key Features

1. **আজকের দামের তালিকা** — হোম পেজে "আজ দাম বেড়েছে ▲" ও "আজ দাম কমেছে ▼" সেকশন (সর্বোচ্চ ৬টি করে) এবং সব পণ্যের রেসপন্সিভ গ্রিড।
2. **লাইভ প্রাইস টিকার** — নেভবারের নিচে অনন্ত স্ক্রলিং স্ট্রিপে ইমোজি, নাম, দাম ও ▲/▼ শতাংশ।
3. **ক্যাটাগরি পেজ ও সর্টিং** — চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মসলা; "সাজান" ড্রপডাউনে বাংলা সংখ্যা সঠিকভাবে সংখ্যাগতভাবে সর্ট হয়।
4. **পণ্যের বিস্তারিত পেজ (প্রটেক্টেড)** — সর্বনিম্ন/সর্বোচ্চ/গড় দাম এবং বাজারভিত্তিক দামের টেবিল; লগইন ছাড়া ঢুকলে সাইন ইন পেজে রিডাইরেক্ট ও টোস্ট।
5. **Better Auth অথেনটিকেশন** — ইমেইল/পাসওয়ার্ড, Google ও GitHub লগইন, টোস্ট নোটিফিকেশন, স্কেলেটন লোডার এবং প্রোফাইলে নাম আপডেট।
6. **৪০৪ পেজ ও লোডিং স্টেট** — ভুল রুটে বন্ধুত্বপূর্ণ ৪০৪ এবং "হোম পেজে ফিরে যান" বাটন।

## 🛠️ Technologies Used

| প্রযুক্তি | ব্যবহার |
| --- | --- |
| Next.js 15 (App Router) | UI ও রাউটিং |
| Tailwind CSS v4 + DaisyUI 5 | স্টাইলিং ও কম্পোনেন্ট |
| Better Auth | অথেনটিকেশন (Email + Google + GitHub) |
| PostgreSQL (`pg`) | Better Auth-এর ডেটাবেস (Neon/Supabase ইত্যাদি) |
| react-hot-toast | টোস্ট নোটিফিকেশন |
| JavaScript | ভাষা |

## 🚀 Run locally

```bash
npm install
cp .env.example .env.local     # মানগুলো পূরণ করুন
npm run auth:migrate           # Better Auth-এর টেবিল তৈরি করে
npm run dev
```

`.env.local`-এ `DATABASE_URL`, `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `NEXT_PUBLIC_APP_URL` এবং (সোশ্যাল লগইনের জন্য) Google/GitHub ক্লায়েন্ট আইডি ও সিক্রেট দিন।

**OAuth callback URL:**
- Google: `<APP_URL>/api/auth/callback/google`
- GitHub: `<APP_URL>/api/auth/callback/github`

## 🌐 Deploy (Vercel)

1. রিপো Vercel-এ ইমপোর্ট করুন।
2. উপরের সব Environment Variable যোগ করুন (`BETTER_AUTH_URL` ও `NEXT_PUBLIC_APP_URL` হবে আপনার Vercel ডোমেইন)।
3. একবার `npm run auth:migrate` চালিয়ে ডেটাবেসে টেবিল তৈরি করুন, তারপর ডেপ্লয় করুন।

## 📦 Data

পণ্যের ডেটা প্রথমে Programming Hero-র `bazardor` API থেকে আনার চেষ্টা করা হয়; API না পাওয়া গেলে `lib/data.js`-এর লোকাল ডেটা ব্যবহার হয়, তাই সাইট কখনো খালি দেখায় না।
